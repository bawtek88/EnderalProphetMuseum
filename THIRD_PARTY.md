# Third-party assets

## DarkFox / Dark's modding resources

This repository contains a limited selection of display-furniture and trophy-base meshes under `meshes/df/`, plus the custom texture `textures/df/materials/dfglassscratched.dds`.

These files were selected from the DarkFox/Dark's resource archive used during development (`PM_DarkAssets.bsa`). They are redistributed under the resource author's open-use permissions. Credit belongs to the original resource author(s).

Only files directly referenced by `ProphetMuseum.esp`, and their required non-vanilla texture, are included. The meshes also reference standard Skyrim textures; those textures are supplied by the required game installation and are not redistributed here.

Before publishing a packaged release outside this source repository, retain this attribution and re-check the current wording of the upstream resource permissions.
